# Retail Sales Data Analysis

Analyzed retail sales data using Excel, Python, PostgreSQL, and Power BI.

### Tools
- Excel
- Python (Pandas, Matplotlib)
- PostgreSQL (SQL)
- Power BI

### Key Insights
- Analyzed sales and profit trends.
- Identified top-performing products and categories.
- Compared regional sales performance.

### Dashboard
Interactive Power BI dashboard for sales and profit analysis.
